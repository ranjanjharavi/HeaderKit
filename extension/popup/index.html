Choose when ReqKit handles your data

ReqKit reads the active tab URL locally to identify the current host and stores profiles, activation settings, and header rules in this Chrome profile.

ReqKit has no analytics or developer server. Header values are sent only to each rule's exact HTTPS host, and only when a site access grant covers it. Destination or intermediary logs may include those values.
