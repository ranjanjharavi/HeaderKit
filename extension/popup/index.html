Review HeaderKit data handling

HeaderKit reads tab URLs locally for the current host and toolbar badges, including background updates on approved sites. Never store URLs or send them to the developer.

Profiles, settings, and header values are stored unencrypted in this Chrome profile. Anyone with access to its files may be able to read them.

HeaderKit has no analytics or developer server. Active header values go only to their exact HTTPS host with site access. Destination or intermediary logs may include them.
