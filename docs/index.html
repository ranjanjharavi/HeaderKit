Before installing

Does ReqKit modify response headers?

ReqKit manages request headers for exact HTTPS hosts. It does not edit response headers, inspect response bodies, or bypass CORS.

Does it have access to every website?

Request exact-host access on demand. Review exact and broader grants through Site access.

Where are rules stored?

Store rules in the current Chrome profile. No accounts, analytics, or developer server. Active values reach matching destinations and may appear in logs. Read the privacy policy.
